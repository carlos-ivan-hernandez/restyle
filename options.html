      themes.json format

      {
  "themes": [
    {
      "name": "Wikipedia-OneSee",
      "description": "Dark theme for Wikipedia",
      "matches": ["*://*.wikipedia.org/*"],
      "css": "themes/wikipedia-onesee.css"
    }
  ]
}
      css paths are relative to themes.json. matches takes Chrome match patterns, or a bare domain like youtube.com for that site and its subdomains.
